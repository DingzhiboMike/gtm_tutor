# gtm-tutor

Тьютор-копилот по курсу GTM для PMM «От идеи к выручке продукта» — пять блоков, модули M0–M13.

Объясняет теорию в терминах курса, разбирает артефакты по рубрикам, штурмит гипотезы, помогает внедрять на практике. Сам курс тут 

## Что внутри

- **`SKILL.md`** — основной файл скилла: логика тьютора, правила разбора домашних заданий, стиль ответов
- **`references/modules/`** — конспекты модулей M0–M13 (JTBD, VPC, позиционирование, месседжинг, каналы, работа с продажами, дерево целей, запуск, рост)
- **`references/instruments/`** — методички по инструментам курса: Dunford, VP Canvas, Left/Right VPC, Fit Map, карта триггеров и пути клиента, launch brief, разбор несостоявшихся сделок, дерево целей, ревизия сигналов

## Структура курса

- **Блок 1 — Про клиента:** M0–M3
- **Блок 2 — Про конкурента и тебя:** M4–M5
- **Блок 3 — Про коммуникацию и каналы:** M6–M8
- **Блок 4 — Работа с продажами:** M9–M10
- **M11–M13:** дерево целей и метрики, запуск, рост (петля обратно в M1 и M4)

## Триггеры активации

«GTM курс», «gtm-tutor», «помоги с модулем N», «разбери домашку», «проверь мой артефакт», а также термины курса — JTBD, VPC, точка слома, Dunford, канвас VP, battle card, дерево целей, launch brief и т.п.

## Использование

Скопировать содержимое репозитория в `/mnt/skills/user/gtm-tutor/` (или соответствующую директорию скиллов в вашей среде) — скилл подключается автоматически по триггерам выше.
